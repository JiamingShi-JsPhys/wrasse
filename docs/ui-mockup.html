wrasse · CLI output design v5

Line-number gutter · labelled why · 2 lines of context by default
本版规则
① 代码左侧有行号 gutter：- 用旧行号，+ 用新行号。
② why 是标签，不是注释——不写 # / //，避免被当成可粘贴代码。
③ 结果页默认前后各 2 行上下文（--context N 可调，0 关闭）；explain / review 里默认各 5 行。
④ 上下文永远来自真实文件；跨不过去就断开，不假装连续。
